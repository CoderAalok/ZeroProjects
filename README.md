# ZeroProjects

A collection of practical web projects focused on solving real-world problems.

## Overview

This repository contains a Hospital Visitor Management System that helps manage visitor registration, verification, approval, and tracking in a healthcare setting.

## Features
- Visitor registration with OTP verification
- Patient search and visit request submission
- Staff/admin approval workflow
- Digital visitor pass with QR code
- Visitor status tracking
- Entry and exit monitoring
- Role-based access for visitors, staff, and patients

## Tech Stack
- HTML
- CSS
- JavaScript

## Run the Project
1. Clone the repository:
   ```bash
   git clone https://github.com/CoderAalok/ZeroProjects.git
   ```

2. Open the project folder:
   ```bash
   cd ZeroProjects
   ```

3. Open `Hospital Visitor Management System/index.html` in your browser.
